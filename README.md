# Shelf
A clean, Apple TV-style home screen for Android TV projectors: greeting and clock,
Bondi weather (Open-Meteo), ABC News headlines, rotating landscape backgrounds,
and a pinned top row of apps.

Install: on the projector, open Downloader and go to `jthhompson18.github.io/shelf`.

Background photos are from Unsplash (Unsplash License): Dillon Hunt (Espiritu Santo, Vanuatu),
Moraine Lake, Peyto Lake (Daniel Tseng), Lake Hāwea, and Jiuzhaigou Valley.
Font: Inter (SIL Open Font License).
